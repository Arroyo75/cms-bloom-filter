# cms-bloom-filter

A Java library implementing probabilistic data structures - Bloom Filter and Count-Min Sketch - build from scratch to understand their inner workings, not as a wrapper around an existing implementation.

# Status

In progress

# Motivation

Exploring probabilistic data structures for cache-penetration protection and cache limiting, and wanting to understand the underlying math and tradeoffs of this approach.

# Planned features

- [ ] Bloom Filter for membership testing
- [ ] Count-Min Sketch for frequency estimation

# Requirements

- JDK 25

# Building

- mvn verify
